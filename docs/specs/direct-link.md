# Прямая связь с агентом

Короткая спека. Владелец пишет каждому агенту на его адрес. Если своего адреса нет, сообщение идёт через общий вебхук Путина. В карточке агента больше нет блока «Доставка».

## Одна строка в карточке

Строка стоит в форме отправки, рядом с полем текста. Это один элемент `data-direct-link`. Блока «Доставка», полей адреса и ключа, кнопки «Проверить» и надписи «Нужен пароль персонала» в карточке нет.

Текст строки, по `deliveryRoute` из `GET /api/state`:

| Кто | Свой адрес есть | Своего адреса нет |
|---|---|---|
| Любой агент, кроме Путина | «Прямая связь: подключена» | «Сообщение уйдёт через Путина» |
| Путин (`grok`) | «Прямая связь: подключена» | «Прямая связь: не подключена» |

Свой адрес у обычного агента — маршрут `agent`. У Путина свой адрес — маршрут `putin` (его вебхук или общий). Маршрут `env` и `none` для Путина — «не подключена», без фразы «через Путина». У Путина этой фразы нет ни в строке, ни рядом с полем.

Прежняя строка «Куда уйдёт приказ» остаётся. Подпись «Путин →», английские имена направлений и замы Финансов только в помещении Финансов не меняются.

## «Служебное» под ключом

Кнопка ключа в шапке открывает и закрывает свёрнутую панель «Служебное» сразу под собой. Пока пароль штаба не введён, в панели только поле пароля. Пароль тот же, `localStorage.appPassword`. Пропуск для «Дать задачу» по-прежнему открывает прежнее окно пароля.

С паролем — все неархивные агенты, включая замов Финансов, по номерам. У каждого: имя, та же строка статуса, поле «Адрес», поле «Ключ» (`type=password`), «Сохранить», «Проверить». Архивных в списке нет. На карте замы по-прежнему только в помещении Финансов.

«Сохранить» вызывает уже существующий `PUT /api/agents/:id/delivery`. Пустой ключ не стирает сохранённый. После сохранения поле ключа пустое. Если ключ есть, рядом только текст «ключ сохранён». Полного ключа нет в панели, в ответе API и в логе.

## «Проверить»

Кнопка есть только в «Служебном», у каждого агента. Она бьёт в его адрес и пишет результат:

| Что случилось | Текст |
|---|---|
| Ответ 2xx | «Доставлено» |
| Нет ответа, обрыв или таймаут | «Адрес не отвечает» |
| Ответ 401 или 403 | «Ключ не подошёл (401/403)» |
| Своего адреса нет | «Адрес не задан — сообщения идут через Путина» |

Тело проверки: `type` равен `ping`, `text` равен «Проверка связи». В очередь, журнал, «Процессы» и счётчики эта проверка не попадает. В логе нет адреса и ключа.
