# Подпись отправителя

На сайте отправитель задачи или сообщения с идентификатором `owner` (и пустой идентификатор в той же ветке) показывается как «Путин → …». Раньше эта подпись была «Владелец → …».

Меняется только текст на экране. `fromAgentId`, `role`, `by`, `closedBy` и прочие поля остаются `owner`. Записи в Postgres не переписываются. Статусы доставки и outbox не входят в эту правку.

Имя отправителя задаёт одна функция `senderName` в `public/js/sender-label.js`. Уже сохранённая строка «Приказ: Владелец → …» при показе в переписке читается через `displayOrderSender` как «Приказ: Путин → …». Слово «Владелец» внутри другой фразы не заменяется.

## Где на экране стоит «Владелец»

Меняем — это подпись отправителя:

- `public/js/app.js`, `whoName` — цепочка в журнале заданий и в панели агента: «Владелец → …».
- `public/js/processes.js`, `person` — маршрут в окне «Процессы сейчас»: «Владелец → …».
- `server.js`, `agentLabel` — системная строка переписки «Приказ: Владелец → …». Новая строка собирается через `senderName`. Старая строка в базе остаётся, подмена только при показе.

Не меняем — здесь «владелец» не подпись отправителя на сайте:

- README: описание поля `fromAgentId` и текст про релей («которые владелец написал»).
- Идентификаторы `owner` в API, базе и коде.
- Класс `.msg-row.owner` и подпись реплики в пузыре переписки «Вы».
- Переменная `owner` при начислении опыта исполнителю.
- Синхронизация с «Порядком», статусы «в очереди агента» и «отправлена Путину».

## Сценарий

1. Поставить задачу с `fromAgentId: "owner"` агенту «Программирование». В ответе API `fromAgentId` равен `owner`. В журнале, в «Процессах сейчас» и в переписке маршрут начинается с «Путин →», системная строка — «Приказ: Путин → Программирование».
2. Сообщение, уже лежащее в базе как «Приказ: Владелец → Программирование», на экране показывается как «Приказ: Путин → Программирование». Текст в базе тот же.
3. Строка «Принял заказ · Владелец ждёт» на экране не меняется.
